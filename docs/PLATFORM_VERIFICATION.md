# Windows / macOS 実機検証計画

このプロジェクトの自動テストは **USB MIDI実機・演奏音の品質を保証しません**。
実機に接続する際は、下記の実測項目を1回ずつ確認してから機能を増やします。

## 対象構成

| 環境 | PC | OS・ドライバー | 検証状態 |
| --- | --- | --- | --- |
| Windows | OMEN 35L（RTX 4070 Ti SUPER） | Windows 10/11向けBOSS GT-1000 Driver | 未実施 |
| macOS | MacBook Pro 16-inch（M1 Max） | BOSS公式の該当macOS対応ドライバー | 未実施 |

*OSバージョン・本体システムバージョン・BOSS TONE STUDIOのバージョンは実測して記録する。未確認のものを推定しない。*

## 手順

1. 接続前に**BOSS TONE STUDIOで全パッチをバックアップ**する。
2. GT-1000COREをUSBで接続。BOSS公式ドライバーの認識状態を確認し、BOSS TONE STUDIOが開いている場合は終了する。
3. PCの音量・アンプの音量を下げ、スピーカー／イヤホンの損傷に注意する。ライブや録音中は試さない。
4. Windows: `scripts/start-windows.bat` / macOS: `scripts/start-macos.command` で起動。OSの実行許可が得られない場合はREADME記載のターミナル手順を使う。
5. UIでMIDI入力・出力の両ポートを明示的に選択。Identity Replyを確認する。
6. 一時パッチの名前、12パラメーター、エフェクトON/OFFを読み込む。BOSS TONE STUDIOまたは本体画面の値と照合する。
7. 最も安全な例として、**ONであるEQ1**の`EQ1 High Gain`を±1 dBだけ変更案として生成する。実機への反映後に本体画面と一致するか確認する。
8. 「直前の変更を戻す」で完全に元の値へ復帰することを確認する。ユーザーパッチの保存状況が変化していないことを確認する。
9. テスト終了後に再読込し、異常がないことを確認する。

## 合否基準

| 項目 | PASS | FAIL / 停止条件 |
| --- | --- | --- |
| ポート認識 | 入出力を選択可能 | ポートが出ない、別機器と混同 |
| 機種判定 | GT-1000COREと判定 | Identity Replyなし、誤判定 |
| 読み取り | 名前・12値・5 ON/OFFが本体と一致 | タイムアウト、値ズレ |
| 反映 | 同意後のみ一時パッチに反映 | 同意なし送信・異なる値が変更 |
| Undo | 反映前の値へ正確に戻る | 復帰せず、他の値も変化 |
| 永続保存 | ユーザーパッチへの書き込みなし | 意図しない保存・別パッチ変更 |
| 安定性 | 連続10回の読込が成功 | タイムアウトまたはUSB切断 |
